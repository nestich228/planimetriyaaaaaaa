# 4 вариант

## О презентации

Интерактивная презентация по геометрии (планиметрии), посвящённая расчету параметров плоских фигур.

## Содержание презентации

1. **Теория и формулы** — описание основных геометрических понятий.
2. **Периметры фигур** — интерактивные калькуляторы для:
    * Круга (через радиус $R$)
    * Трапеции (по четырем сторонам)
    * Треугольника (проверка существования и расчет)
3. **Площади фигур** — инструменты для вычисления:
    * Круга (через радиус и периметр)
    * Трапеции (через основания/высоту и среднюю линию)
    * Треугольника (через основание/высоту и формулу Герона)
    * Квадрата (через сторону и диагональ)
    * Ромба (через диагонали и высоту)
4. **Заключение**

## Использование

* **Стрелки на клавиатуре ← → ↑ ↓** для навигации по разделам.
* **Пробел** для перехода к следующему слайду.
* **Клик мыши** для активации интерактивных кнопок расчета.

## Технологии

* **Reveal.js**— фреймворк для презентаций
* **HTML5, CSS3, JavaScript** — верстка и логика вычислений
* **GitHub Pages** — хостинг презентации
